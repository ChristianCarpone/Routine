ROUTINE 2.1 - installazione e aggiornamento

L'APP SI APRE DA QUI (non dalla pagina github.com del repository):
https://christiancarpone.github.io/Routine/

AGGIORNARE DA UNA VERSIONE PRECEDENTE (i dati gia' inseriti restano)
1. Apri il repository su github.com -> "Add file" -> "Upload files".
2. Trascina: index.html, sw.js e la cartella vendor
   (icons, manifest e LEGGIMI puoi ricaricarli, non cambiano).
3. "Commit changes". Aspetta 1-2 minuti.
4. Sull'iPhone apri l'app, chiudila del tutto (scorri via dal
   multitasking) e riaprila. In Altro deve comparire "versione 2.1".

PRIMA INSTALLAZIONE
1. Repository pubblico su GitHub con tutti i file di questa cartella.
2. Settings -> Pages -> Deploy from a branch -> main, / (root) -> Save.
3. Sull'iPhone apri il link sopra con SAFARI -> Condividi ->
   "Aggiungi alla schermata Home".

NOTE
- I dati restano SOLO sul dispositivo: su GitHub c'e' solo il codice.
- Backup: Altro -> Esporta backup -> salva su iCloud Drive / OneDrive.
- Usa l'app sempre dall'icona sulla Home: cancellare i dati di Safari
  non la tocca, eliminare l'icona invece cancella i dati.
- Lo scanner del codice a barre chiede il permesso della fotocamera
  la prima volta; serve la connessione per cercare il prodotto.
- La cartella vendor contiene la libreria ZXing (licenza Apache 2.0)
  usata per leggere i codici a barre.
